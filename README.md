# 🎬 **프로젝트 소개 - Goottflix**
**Goottflix**는 구독형 OTT 서비스로, **맞춤형 영화 추천**과 **사용자 간 소통 기능**을 강화한 플랫폼입니다.  
이 플랫폼을 통해 사용자들은 개인 선호에 맞는 영화를 추천받고, **새로운 영화**에 대한 정보를 빠르게 확인할 수 있으며,<br>
영화를 감상한 후에는 다른 사용자들과 **실시간 채팅**을 통해 감상평을 공유할 수 있습니다.

관리자는 **사용자 관리**, **영화 DB 관리**, 그리고 **NFC 기반의 가상 영화 예매표 확인 기능**을 통해 혁신적인 사용자 경험을 제공합니다.<br>
또한, **마이페이지와 친구 페이지**를 통해 사용자와 친구의 영화 취향을 비교하고, **통계 데이터 시각화**를 통해 더욱 흥미로운 사용자 경험을 제공합니다.

**Goottflix**는 사용자에게 맞춤형 영화 추천뿐만 아니라 영화 감상 후 다른 유저들과 **소통할 수 있는 기회**를 제공하여 보다 몰입감 있는 영화 경험을 만들어냅니다.  
또한, 관리자에게는 효율적인 운영 도구를 제공하여 플랫폼을 더욱 원활하게 관리할 수 있도록 돕습니다.

## 💡 **기술적 특징**

- **Backend**: Spring Boot와 MyBatis를 사용한 REST API 구현으로 효율적인 데이터 처리  
- **Frontend**: React로 사용자 친화적인 UI 제공 및 실시간 상호작용 강화  
- **Deployment**: AWS를 활용한 서버 배포로 확장성 있는 서비스 운영  
- **추가 기능**: 사용자 맞춤형 알림 시스템, 실시간 채팅, NFC 기반의 가상 티켓 관리  
- **통계 기반 마이페이지**: 사용자와 친구의 영화 취향을 비교할 수 있는 통계 데이터를 제공하여 서로의 선호도와 감상 패턴 확인 가능

## ☀️ 주요 기능

### [ 공통 기능 ]
#### 회원가입, 로그인, 소셜로그인
- 사용자는 이메일, 로그인 아이디, 비밀번호, 닉네임을 이용해 회원가입할 수 있다.
- 이메일 인증을 통해 중복가입 및 무분별한 계정생성을 막을 수 있다.
- 회원가입 시 사용한 로그인 아이디와 비밀번호를 이용해 로그인할 수 있다.


### [ 사용자 기능 ]
#### 영화정보 찾기, 평점남기기, 코멘트달기, 알림, 마이페이지, 친구, 친구페이지, 실시간 채팅, 구독, 영화시청
- 사용자는 새로나온 영화 및 내가 보지않은 영화를 검색하고 세부사항 및 예고편을 볼 수 있다.
- 사용자는 내가 본 영화에 대해 평점남기기 및 코멘트달기를 할 수 있다.
- 사용자는 친구신청, 주목할만한 영화에 대한 알림을 받을 수 있다.
- 사용자는 마이페이지를 통해 자신의 프로필을 수정할 수 있다.
- 사용자는 마이페이지를 통해 자신의 랭킹,평점,코멘트,친구 등에 대한 다양한 통계를 볼 수 있다.
- 사용자는 친구 기능을 통해 다른 사용자와의 교류를 할 수 있다.
- 사용자는 친구페이지를 통해 친구의 프로필 및 친구가 본 영화, 함께 좋아하는 영화, 친구의 랭킹 등의 통계들을 볼 수 있다.
- 사용자는 채팅방을 통해 다른유저와 실시간 채팅 및 이미지를 주고 받을 수 있다.
- 사용자는 구독을 통해(카카오페이) 해당 서비스를 구독할 수 있다. (테스트 결제)
- 사용자는 구독이후에 해당 영화를 시청할 수 있다. (저작권 문제로 인한 실제 영화시청x)

### [ 관리자 기능 ]
#### 회원관리, 영화알림 보내기, 영화 데이터베이스 CRUD, 아두이노NFC
- 관리자 페이지는 해당 유저가 관리자 권한일 경우에만 접근 및 요청이 가능하다.
- 관리자는 회원관리를 통해 유저들의 정보를 열람하고 관리자 및 회원으로 등급변경을 할 수있다.
- 관리자는 영화 알림 보내기 버튼을 통해 주목할 만한 영화에 대해 사용자에게 알림을 보낼 수 있다.
- 관리자는 영화 데이터베이스를 작성,수정,삭제를 통해 관리할 수 있다.
- 관리자는 아두이노 NFC카드를 회원에게 등록시키고 사용자의 영화관 예매내역, 입장(가상)정보를 확인할 수 있다.
